# 3D 動物跳棋 (Chinese Checkers 3D)

專為國小電腦課「完成作業後獎勵」設計的 3D 動物跳棋人機對戰遊戲。

---

## 🌟 最新版本更新重點 (v1.3)

1. **修正棋子初始陣營與基地錯誤（核心修復）**：
   - 🔴 **紅色小兔隊 🐰**：出生在 **【紅色基地】** (South)，目標為正對面的 **【粉紅色歸宿 🎯】**。
   - 🔵 **藍色企鵝隊 🐧**：出生在 **【藍色基地】** (Top-Left)，目標為正對面的 **【水藍色歸宿 🎯】**。
   - 🟢 **綠色青蛙隊 🐸**：出生在 **【綠色基地】** (Top-Right)，目標為正對面的 **【青綠色歸宿 🎯】**。
   - **粉紅色與水藍色目的地初始皆為 100% 空白，企鵝絕不會再跑到小兔的粉紅目的地中！**
2. **多向向量式 AI 導航**：
   - 電腦 AI 企鵝具備獨立目標向量，會精準朝向自己的水藍色陣營跳躍推進，並在中央棋盤與小兔產生交會跳躍。
3. **專屬浮空動態路標**：
   - 各陣營目標尖端皆有獨立的浮空徽章（例如：`🎯 小兔歸宿 (粉紅區 🐰)` 與 `🎯 企鵝歸宿 (水藍區 🐧)`），旋轉視角永不迷航。
4. **金黃色提示光盤**：
   - 合法跳躍落點為實心向日葵金黃色光盤與橙黃光環，對比清晰，不與任何動物或地盤顏色混淆。

## 🚀 如何在 Google 協作平台 (Google Sites) 嵌入使用

1. 打開您的 **Google 協作平台 (Google Sites)** 編輯頁面。
2. 在右側面板點擊 **「插入 (Insert)」** ➔ **「嵌入 (Embed)」**。
3. 切換至 **「嵌入程式碼 (Embed Code)」**。
4. 將 `index.html` 內的完整程式碼複製並貼上。
5. 點擊 **「下一步」** ➔ **「插入」**。
6. 將區塊拉寬並將高度設定為 700px 以上即可發布！
